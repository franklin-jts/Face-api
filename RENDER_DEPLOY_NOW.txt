================================================================================
🆘 IF SOMETHING GOES WRONG
================================================================================

Deployment Failed?
  1. Check Render dashboard → Service → Logs
  2. Look for red error messages
  3. Most common issues:
     - Missing render.yaml → Fix: Make sure file is in project root
     - Wrong branch → Fix: Select "dev_new"
     - Models not included → Fix: Run "git add models/"

Service won't start?
  1. Check if models/ folder is in GitHub
  2. Run: git ls-files models/
  3. Should show 3 ONNX files
  4. If missing, add them: git add models/ && git commit

Health check fails?
  1. Service might still be starting
  2. Wait 2 minutes
  3. Try again
